# OpsPilot v4.1.3 — Public Showcase

OpsPilot v4.1.3 is the public showcase release of an AI-assisted infrastructure operations platform.

## Highlights

- Multi-site / multi-datacenter operations
- VMware vCenter inventory and health collection
- Zabbix problem and incident integration
- Active ICMP/TCP diagnostics
- Incident correlation and root-cause classification
- Confidence-aware operator guidance
- Playbook generation and remediation queue
- Human approval for sensitive changes
- Post-action verification and audit history
- Bilingual Persian/English Telegram operator workflows
- Web dashboard and fleet reporting
- Grounded AI incident analysis
- Safe degraded mode when the AI provider is unavailable or rate-limited

## Safety model

OpsPilot is designed to assist operators, not silently control production infrastructure. Sensitive actions remain approval-gated and recovery is independently verified after execution.

## Public-showcase scope

This release intentionally excludes production source code, credentials, internal IP addresses, hostnames, company topology, production site configuration, private logs, and incident data.

The production implementation remains in a separate private repository.
